2. 테스트 설명 카드

벽과의 거리와 태그 방향을 분리해서 읽도록 문장을 다시 정리했습니다. 실제 수행한 테스트만 빠르게 훑을 수 있도록 카드만 남겼습니다.

사람 영향 테스트는 이 페이지 구조도에서 제외

1. 벽걸이 밀집/분산 비교

1-1 ~ 1-3

1-1: 옷 7벌을 한 훅에 모두 걸고, 벽과의 거리 혼합, 태그 방향 혼합 상태에서 안테나 중-중으로 측정한 테스트.

1-2: 옷 7벌을 3-2-2 분산으로 걸고, 벽과의 거리 혼합, 태그 방향 혼합 상태에서 안테나 중-중으로 측정한 테스트.

1-3: 옷 7벌을 3-1-2-1 분산으로 순차 배치하고, 벽과의 거리 혼합, 태그 방향 혼합 상태에서 안테나 중-중으로 측정한 테스트.

2. 재질 차폐 비교

1-8 ~ 1-11

1-9: 옷 5벌을 중앙훅에 걸고, 추가 재질 없이 안테나 중-중으로 측정한 기준 테스트.

1-8: 1-9 기준 배치에 바람막이만 추가한 뒤 측정한 테스트.

1-10: 1-9 기준 배치에 청바지만 추가한 뒤 측정한 테스트.

1-11: 1-9 기준 배치에 청바지 + 바람막이를 모두 추가해 재질 차폐를 비교한 테스트.

3. 청바지/바람막이 추가 비교

1-4 ~ 1-7, 1-12

1-6: 청바지, 바람막이 모두 제외한 기본 5벌 비교 테스트.

1-5: 1-6 기준 배치에 청바지만 추가하고 바람막이는 제외한 테스트.

1-7: 1-6 기준 배치에 바람막이만 추가하고 청바지는 제외한 비교 테스트.

1-4: 1-6 기준 배치에 청바지와 바람막이를 모두 추가한 상태를 측정한 테스트.

1-12: 왼쪽 2개 + 바로 옆 1개 + 중앙 2개 + 오른쪽 청바지처럼 특수 배치한 테스트.

4. 바닥 적층 방향 비교

2-1 ~ 2-3, 2-5 ~ 2-7

2-1: 옷 7벌을 바닥 적층하고 최하단 19번만 안테나를 바라보게 둔 상태에서 측정한 테스트.

2-2: 최하단 19번만 안테나 반대 방향으로 두고 측정한 테스트.

2-3: 최하단 19번 외 나머지만 안테나를 바라보게 만든 적층 비교 테스트.

2-5: 전체 태그를 안테나 반대 방향으로 정렬한 적층 테스트.

2-6: 가장 위 10번만 안테나를 바라보게 만든 적층 테스트.

2-7: 19번만 안테나를 바라보게 만든 적층 테스트.

5. 바닥 랜덤 배치 비교

2-4

2-4: 옷 7벌을 바닥에 랜덤 분산하고 벽과의 거리 혼합, 태그 방향 혼합 상태에서 측정한 테스트.

6. 안테나 위치 비교

1-5 new, 2-1 ~ 2-6 new, 3-2 new, 3-6 new

파일명 기준 매핑: 정면=벽과 멂, 후면=벽과 가까움, 왼쪽훅/중앙훅/오른쪽훅=벽걸이 위치, 안테나 왼쪽/중앙/오른쪽=같은 조건에서 안테나 위치만 바꿔 본 비교입니다.

옷밖/옷안, QR 보임/안보임은 파일명에 적힌 실제 배치 조건 그대로 남겼습니다. 이 부분은 안테나 위치 테스트의 세부 배치 조건으로 보고, 구조도 핵심 축과는 별도로 읽는 것이 안전합니다.

2-6 new: 파란셔츠 1벌을 후면 중앙훅, 즉 벽과 가까운 중앙훅에 두고 옷밖 QR 보이게 배치한 상태에서 안테나 왼쪽 / 중앙 / 오른쪽을 비교한 테스트.
