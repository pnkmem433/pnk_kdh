# report_html

## 파일 설명
- `index.html`
  - 사수 보고용 RFID 대시보드 초안
- `data.js`
  - 보고서 문구, 카드 내용, 사진 링크 자리, Mermaid 도식 코드를 모아둔 설정 파일
- `AI_모듈화가이드.md`
  - 이후 각 모듈을 AI로 다듬거나 확장할 때 쓰는 구조 가이드

## 바로 써보는 방법
1. 브라우저에서 `index.html`을 연다
2. `data.js`에서 사진 `src` 값을 채운다
3. Google Drive 링크는 아래 둘 중 아무 형식이나 넣어도 된다
   - `https://drive.google.com/open?id=...`
   - `https://drive.google.com/file/d/...`
4. 페이지를 새로고침하면 이미지가 바로 반영된다

## 추천 이미지 우선순위
1. 한 훅 밀집 실패 사진
2. 훅 분산 회복 사진
3. 바닥 적층 성공 / 실패 비교 사진
4. 사람 유무 비교 사진
5. 안테나 왼쪽 / 중앙 / 오른쪽 비교 사진
6. Phase 1 또는 옷 1벌 기준점 사진

## 이 구조가 좋은 이유
- 기준점과 본론이 분리되어 있다
- 실패 원인과 해결 방향이 한 화면에 같이 있다
- 외부 자료 방어 카드가 본문 안에 들어간다
- 사진을 부록이 아니라 결론 근거로 바로 쓸 수 있다
