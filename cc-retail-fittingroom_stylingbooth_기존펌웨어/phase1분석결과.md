# Phase 1 분석결과

## 목적
- 이 문서는 Phase 1 테스트의 위치별, 방향별 RFID 인식 기준선을 정리하는 기준 문서이다.
- 이후 Phase 2 결과를 분석할 때, Phase 2의 조건과 가장 가까운 Phase 1 조건을 찾아 함께 비교하는 용도로 사용한다.
- 특히 아래 항목을 확인하기 위한 기준선으로 사용한다.
  - 위치 자체의 음영지역 여부
  - 방향 변화에 따른 기본 인식 편차
  - 특정 위치에서의 기본 인식 횟수 수준
  - 특정 위치에서의 최초 인식 속도 수준

## Phase 1 기본 조건
- 기준점 태그:
  - `U30004954303030313100000000001C1A`
  - 바닥 중앙 RFID 태그
- 비교점 태그:
  - `U3000BB09001D620901702570918DDEC9`
  - 측면에 위치할 RFID 태그
- 반복 측정 방식:
  - 각 테스트별 5회 측정
  - 최고치 1개, 최저치 1개 제외
  - 나머지 3회의 평균값을 최종 통계 데이터로 사용

## Phase 1 측정 목적
- 최초 인식 속도 및 10초 스캔 윈도우 내 응답성 확인
- 최소 스캔 횟수 충족 여부를 통한 서버 전송 안정성 검증
- 위치 및 방향에 따른 기본 인식 편차 확인
- 부스 내부에서의 하드웨어 음영지역 여부 확인

## Phase 1 결과 기록 규칙
- 숫자는 보정 없이 그대로 기록한다.
- 각 조건은 아래 항목으로 정리한다.
  - 기준점 태그 평균 인식 횟수
  - 기준점 태그 최초 인식 시간
  - 비교점 태그 평균 인식 횟수
  - 비교점 태그 최초 인식 시간
  - 10초 내 인식 여부
  - 서버 전송 여부
  - 특이사항
- 최초 인식 시간이 없으면 `-`로 표기한다.

## Phase 1 해석 기준

### 1. 위치 영향
- 같은 방향인데 위치만 바뀌었을 때 평균 인식 횟수 차이가 크면 위치 영향으로 본다.
- 특정 위치에서 최초 인식 시간이 반복적으로 느리거나 인식 실패가 발생하면 음영지역 가능성이 높다.

### 2. 방향 영향
- 같은 위치인데 정방향, 뒤집힘, 세워짐에 따라 인식 횟수가 달라지면 방향 영향으로 본다.
- 세워짐에서만 급격히 낮아지면 안테나 방향성 영향을 우선 의심한다.

### 3. 전송 안정성
- 평균 인식 횟수가 최소 스캔 횟수 기준에 근접하거나 미달하면 서버 전송 안정성이 낮은 조건으로 본다.
- 10초 내 인식은 되지만 누적 인식 횟수가 낮으면 `읽힘은 되나 전송 여유가 부족한 조건`으로 본다.

## Phase 2 분석 시 참조 규칙
- Phase 2 분석은 반드시 `분석 지침2.md`를 기준으로 수행한다.
- 다만 Phase 2 결과를 해석할 때는 이 문서에서 가장 가까운 Phase 1 기준선을 찾아 함께 비교한다.

### 참조 우선순위
- `바닥 중앙` 테스트:
  - Phase 1의 `중앙 위치` 결과를 먼저 참조한다.
- `바닥 왼쪽` 테스트:
  - Phase 1의 `왼쪽 위치`, 필요 시 `왼쪽아래 위치` 결과를 함께 참조한다.
- `바닥 오른쪽` 테스트:
  - Phase 1의 `오른쪽 위치`, 필요 시 `오른쪽아래 위치` 결과를 함께 참조한다.
- `바닥 앞쪽` 테스트:
  - 방향과 실제 배치에 따라 `아래쪽 위치` 결과를 우선 참조한다.
- `바닥 뒤쪽` 테스트:
  - 실제 안테나 배치상 가까운 축을 기준으로 `왼쪽위`, `오른쪽위`, `높은 곳 위치` 중 가장 유사한 조건을 참조한다.
- `옷걸이 상단/높은 위치` 테스트:
  - `왼쪽 높은 곳 위치`, `오른쪽 높은 곳 위치` 결과를 우선 참조한다.
- `옷걸이 측면` 테스트:
  - 가장 가까운 `왼쪽 위치` 또는 `오른쪽 위치` 결과를 참조한다.

## Phase 2와 비교할 때 보는 항목
- 같은 위치 계열에서 Phase 1 대비 인식 횟수가 얼마나 감소했는지
- 같은 위치 계열에서 Phase 1 대비 최초 인식 시간이 얼마나 느려졌는지
- Phase 1에서는 안정적이었는데 Phase 2에서만 누락되었는지
- 위치 영향보다 의류 차폐 영향이 더 큰지
- 위치 영향보다 다중 태그 간섭 영향이 더 큰지

## Phase 2 해석 문장 예시
- `이 조건은 Phase 1 중앙 위치 기준선에서는 안정적으로 읽히던 구간이므로, 이번 저하는 위치 자체보다 의류 중첩 영향 가능성이 높다.`
- `이 조건은 Phase 1 왼쪽 위치에서도 상대적으로 약했던 구간이어서, 이번 결과는 바닥 왼쪽 위치 영향과 의류 차폐 영향이 함께 작용했을 가능성이 높다.`
- `Phase 1 높은 위치 기준선에서도 인식 횟수가 낮았다면, Phase 2 옷걸이 상단 저하는 구조적 음영 영향이 포함되었을 가능성이 있다.`
- `Phase 1에서는 동일 방향에서 문제가 없었으므로, 이번 누락은 태그 간 간섭 또는 중첩 순서 영향일 가능성이 더 높다.`

## 작성 메모
- 여기에 실제 Phase 1 평균값을 채워두면, 이후 AI가 Phase 2를 분석할 때 해당 위치와 방향에 맞는 기준선을 함께 참조해 해석할 수 있다.
- Phase 1 수치가 아직 완전히 정리되지 않았다면, 우선 조건명과 해석 규칙부터 유지하고 나중에 표만 채워도 된다.
