# Phase 2(옷 여러벌) 분석결과

## 목적
이 문서는 `Phase 2(옷 여러벌)` RFID 테스트 CSV를 기준으로, 여러 벌이 함께 있을 때 어떤 조건에서 인식이 무너지는지 빠르게 파악하기 위한 종합 분석 문서다.

이 문서만 봐도 아래 내용을 바로 알 수 있도록 정리했다.

1. 어떤 실험을 왜 했는지
2. 어떤 태그가 어떤 조건에서 강하고 약한지
3. 실패 원인이 옷 재질 차폐인지, 위치/방향/밀집/사람/안테나 위치 문제인지
4. 이후 개선 테스트를 어디부터 해야 하는지

---

## 문서 사용 기준

### 판정 기준
- 문제 조건: 여러 벌 중 목표 태그들 중 하나라도 인식 조건을 못 넘는 경우
- 통과 기준: `10초 이내 5번 이상 인식`
- 위 두 조건을 모두 만족하지 못하면 `인식 X`로 본다

### 통계 기준
- 각 조건은 기본적으로 반복 측정값을 사용했다
- 표에 적은 대표값은 사용자가 기존에 정리한 절사평균 기준을 그대로 반영했다
- 상세표에는 회차별 `인식 횟수 / 처음 인식된 시각(ms)`를 같이 적었다

### 해석 우선순위
이번 문서는 단순히 "몇 번 읽혔다"만 적는 것이 아니라, 아래 우선순위로 원인을 해석한다.

1. 재질 차폐 영향이 큰가
2. 태그 위치와 앞뒤 순서가 더 큰가
3. 바닥 적층 시 방향 정렬이 지배적인가
4. 사람 존재가 악화 요인인가
5. 안테나 위치 변경으로 회복 가능한가

## 전체 결론 먼저 보기

### 가장 중요한 결론
1. `옷 재질 자체의 차폐 영향은 생각보다 작았다`
2. `실패의 주원인은 태그 위치, 태그끼리의 겹침, 벽 근접, 방향 정렬, 안테나와의 상대 위치`였다
3. `사람 존재는 대체로 악화 요인`이지만, 사람보다 `배치 재편`의 영향이 더 큰 경우가 많았다
4. `안테나 위치를 바꾸면 기존 실패 케이스가 회복되는 경우가 많았다`
5. 따라서 개선 우선순위는 `재질 변경`보다 `태그 위치/방향/안테나 위치 최적화`가 맞다

### 실무 적용 요약
- 여러 벌 조건에서 인식 실패가 나오면 먼저 `옷 재질`보다 `태그 방향/겹침/훅 위치/벽과의 거리`를 의심해야 한다
- 바닥 적층에서는 "누가 정방향이고 누가 역방향인지"가 전체 균형을 크게 바꾼다
- 파란셔츠처럼 특정 태그가 약한 경우에도, 안테나 위치 이동만으로 회복되는 사례가 확인됐다
- 청바지 태그는 다수 조건에서 약했으므로, 청바지 태그는 별도 개선안 후보로 관리하는 것이 좋다

### 한 줄 결론
안테나 위치는 인식 결과에 큰 영향을 주었고, 기존 위치에서 실패하던 4개 케이스가 `위치 이동만으로 모두 최소 1개 방향에서는 5회 이상으로 회복`되었다. 다만 최적 위치는 케이스마다 달라서, `1-5와 3-2는 오른쪽`, `2-5는 왼쪽`, `3-6은 중앙`이 가장 유리했다고 보는 것이 타당하다.

### 안테나 위치는 왜 오른쪽이 자주 좋았는가
| 항목 | 정리 |
| --- | --- |
| 전체 경향 | 4개 실패 케이스 중 3개에서 오른쪽 안테나가 통과하거나 가장 강하게 회복되어, 이번 공간에서는 전체적으로 오른쪽이 가장 유리한 편이었다 |
| 왜 그랬는가 | 실패 케이스들에 후면 태그와 오른쪽훅/벽 근접 조건이 많아서, 오른쪽 안테나가 태그 면을 더 정면에 가깝게 봤을 가능성이 크다 |

## 최종 종합 해석

### 1. 재질 차폐는 주원인이 아니다
바람막이만, 청바지만, 바람막이+청바지 조건을 비교해도 대부분 태그는 유지되었고, 무너질 때도 전체가 같이 무너지기보다 특정 태그만 선택적으로 붕괴했다. 이는 `재질 자체`보다 `태그 개별 위치/겹침/방향` 영향이 더 크다는 뜻이다.

### 2. 여러 벌 조건에서는 태그별 유불리가 뒤바뀐다
한 훅 밀집, 훅 분산, 바닥 적층, 바닥 랜덤 배치를 보면 "전체 성능이 같이 좋아지거나 같이 나빠지는 구조"가 아니었다. 즉, 시스템 전체의 평균 문제라기보다 `태그별 상대 위치 문제`가 핵심이다.

### 3. 바닥 적층에서는 방향 정렬이 매우 크다
특히 `2-1 ~ 2-7` 조건은 누가 정방향이고 누가 역방향인지에 따라 강한 태그가 완전히 바뀌었다. 같은 7벌이어도 `방향 정렬만 바꿔도 강한 태그와 약한 태그가 뒤집힌다`는 점이 중요하다.

### 4. 사람은 보통 악화 요인이다
사람이 들어오면 일부 약한 태그가 조금 회복되는 것처럼 보여도, 전체적으로는 기존에 강했던 태그들이 약해지는 경향이 더 컸다. 따라서 실무적으로는 `사람 존재 = 보통 손해`라고 보는 편이 안전하다.

### 5. 안테나 위치는 확실한 개선 포인트다
기존에 실패했던 케이스들이 안테나 위치 변경만으로 회복되었다는 점은 매우 중요하다. 이는 향후 개선 작업에서 `태그 위치/방향 조정`과 함께 `안테나 위치 최적화`가 가장 현실적인 개선축임을 보여준다.

## 실무 적용 포인트

### 우선 개선해야 할 항목
1. 태그를 옷 안쪽 깊숙이 매몰시키는 배치 피하기
2. 태그끼리 평행하게 겹쳐지는 적층 구조 줄이기
3. 벽에 가까운 훅 조건에서 태그 방향 다시 점검하기
4. 청바지 태그는 별도 개선 후보로 분리 관리하기
5. 안테나 위치를 고정값으로 보지 말고, 조건별 최적 위치 후보를 두기

### 후속 테스트 추천 순서
1. 실패가 반복되는 태그만 골라 `태그 부착 위치` 변경 테스트
2. 같은 옷 배치에서 `안테나 위치`만 이동하는 정밀 스윕 테스트
3. `정방향/역방향`을 태그별로 통제한 적층 테스트
4. `벽 근접 거리`를 조금씩 바꾸는 테스트
5. 청바지 태그만 대상으로 한 별도 개선 검증

### AI/노션/HTML 정리용 핵심 메시지
- 이번 여러 벌 테스트의 핵심 실패 원인은 `옷 재질 차폐`보다 `태그 위치/방향/겹침/안테나 상대 위치`다
- 특히 바닥 적층에서는 방향 정렬 하나만 바꿔도 어떤 태그가 강하고 약한지가 완전히 바뀐다
- 사람 존재는 대체로 악화 요인이며, 파란셔츠 일부 회복이 보여도 전체적으로는 손해가 더 크다
- 안테나 위치 이동만으로 실패 케이스가 회복되었으므로, 가장 실용적인 개선 방향은 `태그 구조 최적화 + 안테나 위치 최적화`다
