# 배선 안내

이 문서는 **현재 코드 설정값**을 기준으로 배선을 정리한 것입니다.
핀 번호는 `nfc_master/src/main.cpp`, `nfc_slave/src/main.cpp` 기준입니다.

## 공통

- I2C는 **SDA/SCL + GND**를 반드시 공통으로 연결하세요.
- 전원(VCC)은 사용하는 보드/모듈 사양에 맞게 연결하세요.

## nfc_master (I2C 마스터)

| 항목 | 연결 |
|---|---|
| SDA | D4 (GPIO 4) |
| SCL | D5 (GPIO 5) |
| GND | 슬레이브 GND와 공통 |

## nfc_slave (I2C 슬레이브 + RC522 + 디스플레이)

### I2C

| 항목 | 연결 |
|---|---|
| SDA | GPIO 2 |
| SCL | GPIO 3 |
| GND | 마스터 GND와 공통 |

### RC522 (SPI)

| RC522 핀 | 슬레이브 GPIO |
|---|---|
| SCK | 18 |
| MISO | 17 |
| MOSI | 16 |
| SDA/SS | 21 |
| RST | 1 |
| GND | GND |
| 3.3V | 3.3V |

### 디스플레이 (T-Display-S3)

- `TFT_eSPI` 기본 설정을 사용합니다.
- 보드 기본 배선을 그대로 사용합니다.

## I2C 주소

- 현재 슬레이브 주소는 `0x09`로 설정되어 있습니다.
  - 설정 위치: `nfc_slave/src/main.cpp`

## 주의

- 위 배선은 **현재 코드 기준**입니다. 보드 배선이 다르면 코드의 핀 값부터 수정하세요.
