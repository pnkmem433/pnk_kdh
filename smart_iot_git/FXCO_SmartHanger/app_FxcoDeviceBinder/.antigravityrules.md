디자인 스타일을 Toss / Apple 계열의 미니멀 UI로 설정한다.

Apple 70% + Toss 30% 감성으로 디자인한다. Apple의 여백·정돈감 위주, Toss의 친절한 강조 색과 버튼 톤만 일부 차용한다.

디자인 원칙:
- 시각적 위계가 명확한 단일 컬럼 중심 레이아웃
- 불필요한 장식 제거, 정보 밀도 최소화
- 여백을 넉넉히 사용 (Apple Human Interface Guidelines 수준)
- 카드/버튼은 둥근 모서리, 얕은 그림자 또는 그림자 없음
- 강조 색상은 1개만 사용 (Toss 블루 계열)

타이포그래피:
- 산세리프 기반, 굵기 차이로 위계 표현
- 제목은 bold, 본문은 regular
- 줄간격은 여유 있게

컬러:
- 기본 배경은 화이트 또는 아주 연한 그레이
- 텍스트는 완전 블랙 대신 다크 그레이
- 인터랙션 요소만 포인트 컬러 사용

컴포넌트 규칙:
- 버튼은 단일 primary 스타일
- 아이콘은 단색, line 기반
- border 최소화
